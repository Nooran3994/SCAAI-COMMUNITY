## How items get on the roadmap

1. A community member opens a [feature request](https://github.com/Nooran3994/SCAAI-COMMUNITY/issues/new?template=feature_request.md).
2. Maintainers triage: label `enhancement`, assign priority.
3. Approved ideas move to *Under consideration* above.
4. When work starts, the item moves to *In preview* with the target version.

## Status labels

| Label | Meaning |
|---|---|
| `enhancement` | Proposed or approved feature |
| `bug` | Confirmed defect |
| `review` | Community review / feedback thread |
| `documentation` | Docs or README change |
| `good first issue` | Beginner-friendly task |
| `won't fix` | Reviewed and declined, with reason in comments |
