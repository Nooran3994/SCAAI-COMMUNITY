# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability in SCAAI Desktop, please report it privately — **do not open a public issue**.

**Report via email:** security@scaai.app

Please include:
- The version of SCAAI Desktop affected
- A description of the vulnerability
- Reproduction steps (if known)

We acknowledge receipt of security reports within **48 hours** and work to address validated issues in a timely manner.

## Scope

This policy applies to the SCAAI Desktop application and its auto-update infrastructure.

## Out of Scope

- Issues requiring physical access to the target machine
- Social engineering of SCAAI users
- Previously reported and patched vulnerabilities
